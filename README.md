# Python Learning Projects

A collection of beginner Python projects I created while learning programming fundamentals, data analysis, and machine learning.

## Projects

### Online Store Checkout
A checkout calculator that uses:
- user input
- conditionals
- logical operators
- percentages
- formatted output

File: `online_store_checkout.py`

### Decision Tree Demo
A basic machine learning example using scikit-learn to train a decision tree classifier on sample height, weight, and shoe-size data.

File: `decision_tree_demo.py`

### Stock Regression Demo
A practice stock-price regression project using:
- CSV data
- NumPy
- scikit-learn
- Support Vector Regression
- Matplotlib

File: `stock_regression_demo.py`

The included `aapl.csv` file contains synthetic practice data used for learning and testing.
